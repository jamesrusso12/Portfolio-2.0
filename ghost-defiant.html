Ghost Defiant

A Mixed-Reality ghost-hunting shooter for Quest 3, built solo over roughly eight months as my Boise State senior capstone.

Source on GitHub Full playthrough

The challenge

Design a Mixed-Reality ghost-hunting shooter that feels good on Quest 3 hand-tracking, with a readable HUD, tight shoot feel and stable performance, in a semester, solo.

What I built

  • Custom debris and impact physics on Unity 6's physics system for destructible environments.
  • Spatial audio and fog VFX pipeline tuned for MR passthrough, so threats are legible by sound alone.
  • Hand-tracking-first interaction model, with grab thresholds, haptics and a spatial reticle tuned against playtest data.
  • Diegetic HUD designed for MR comfort: no eye-attached text, high-contrast glyphs.

Outcome

  • 72 FPS stable on Quest 3 with full hand-tracking and passthrough.
  • Solo-shipped core loop, level, VFX, audio and UI.
  • Selected for the Boise State senior showcase.

Stack: Unity 6 · C# · Meta AIO SDK v72 · Hand Tracking · Passthrough API · Spatial Audio · Blender
