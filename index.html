Featured Project: Ghost Defiant

My Boise State University capstone project, a Mixed Reality ghost-hunting shooter built with Unity 6 and Meta AIO SDK v72 for Quest 3. I designed and developed every aspect of the game, from core gameplay logic and optimized physics systems to custom UI/UX design. This project represents the culmination of my degree and demonstrates my skills in Unity development, VR/MR systems, and immersive media.

Key Features

  • Implemented custom debris physics using Unity 6's physics system for interactive environment destruction
  • Engineered spatial audio and fog particle systems for immersive atmosphere and gameplay feedback
  • Optimized for Meta Quest 3 achieving stable 72 FPS with hand tracking, passthrough integration, and spatial awareness
  • Designed custom UI/UX with ghost-hunter aesthetic HUD optimized for VR/MR comfort and accessibility
  • Tech Stack: Unity 6, Meta AIO SDK v72, Quest 3, Hand Tracking, Passthrough API, Spatial Audio
