# Claude — Project Instructions for Portfolio-2.0

Conventions and preferences for Claude when working on this repo.

## Writing style

- **Do not use the em-dash character (`—`, U+2014) in any prose.** Use a
  comma, colon, parentheses, or a sentence break instead. Regular hyphens
  (`-`) inside compound words are fine.
- This applies to chat responses, code comments, commit messages, README
  copy, and any other prose written for the project.
